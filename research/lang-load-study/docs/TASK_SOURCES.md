# Task sources and adaptations

This file is for reviewers, not participants. For every task in the platform it says
which established paradigm it comes from (if any), how far it is from that paradigm, and
what I changed for this study. Nothing here is shown on timed participant screens.

## How to read this table

- **Paradigm family / source.** The classic task the module is built on, with the
  citation that is usually given for it (author + year). I only name a source where I am
  confident it is the standard one. Where I am not sure, the entry says **to verify**,
  and it needs checking against the original paper before anything is published. I
  have not cited page numbers anywhere, on purpose: I have not checked printed pages.
- **Status.**
  - *direct*: close to the standard form of the task (still translated and run in a browser).
  - *adapted*: a recognisable version of a classic paradigm, changed in ways listed in
    the last column. Changes like these can alter what the task measures, so published
    norms and reliabilities for the original task do **not** carry over automatically.
  - *study-specific*: designed for this study. There is no validated original to lean on.
- **Changes common to almost every task** (not repeated on every row):
  1. Shortened to one short block or one puzzle per trial (roughly 10-90 s), because
     every task is repeated twice per round, once in each language.
  2. Items come in matched pairs: the two items of a pair have the same structure and
     difficulty settings, one is shown with the L1 clue and one with the L2 clue.
     "Same structure" is a design intention checked by the generator; it is not proof
     that the two items are equally hard for people.
  3. All content is original and generated by code (no copied test items or pictures).
  4. Instructions and clues exist in 30 languages. English is the source; the other 29
     are machine translations that no native speaker has reviewed yet.
  5. Scoring is done on the server from an independent answer key (solver, simulator
     or parser).

The "card" number is the task's number in my study specification. Gaps in the numbering
(02, 13, 17, 50, 59, 60) are cards that were not built.

## Study choices that are not from any source

- **The "I'm exhausted" button and time to exhaustion as an outcome.** My choice. It is
  a self-report of when someone wants to stop, not a validated fatigue measure.
- **The 60-minute safety maximum.** My choice, for participant burden and the consent
  form. It is not a value from the literature.
- **The 0-100 "How mentally tired do you feel right now?" rating after each round.**
  A visual-analogue-style self-report that I wrote; its wording and scale are mine (to
  verify against an established fatigue scale before use).
- **Mixing L1 and L2 items within every round.** My design choice (see the protocol,
  "What this design estimates").

None of these come from *Cognitive Load Theory* (Sweller, Ayres & Kalyuga, 2011). The
book gave me the research question and the idea that reading in a less comfortable
language could use up working memory. It does not prescribe a session length, an
exhaustion button, or this task battery.

## Core tasks (the ones in the default round mix)

These seven tasks are in `config.ROUND_MIX` and make up every round (2 items each, one
per language). The surprise image and word retention happen once per session.

| Task | Card | Paradigm family / source | Status | What it does and what was changed |
|---|---|---|---|---|
| Surprise image (gorilla) | – | Inattentional blindness: Simons & Chabris (1999); in radiology, Drew, Võ & Wolfe (2013) | adapted | Find a small white ring on a scan; an unannounced gorilla silhouette is also present. Uses placeholder scans until the lab provides real ones. Three follow-up questions on separate pages. The clue language is assigned between people. Drew et al. used real lung CT stacks and expert readers; this is one 2D image and mostly non-experts |
| Search scene | – | Conjunction visual search: Treisman & Gelade (1980) | adapted | Original cluttered scene; the target is a unique object-and-colour pair named in the written clue; distractors share its shape or its colour. Classic visual search uses simple shapes and controlled set sizes; here set size and layout are not systematically varied |
| Scan | – | Detection of a faint target in a medical-style image (lesion-detection style) – to verify | study-specific | Grayscale image with a small, faint planted silhouette. The clue does not name it ("something is out of the ordinary"). No diagnosis is asked. Contrast +16 to +22 grey levels |
| Dice board | – | Following spoken/written instructions while holding information in mind – to verify | study-specific | 9x9 grid, star on the start square, two dice. The clue gives directions in words; the numbers are only on the dice. Click the end square |
| Corsi blocks | – | Corsi block-tapping: Corsi (1972) | adapted | Nine squares light up in sequence (500 ms on, 500 ms off); the clue says to repeat them in the same or reverse order. Both items of a pair have the same length and direction. Time is measured from the end of the sequence to the last click |
| Reading passage | – | Reading comprehension with a two-sentence inference – to verify | study-specific | Short original passage and one question that needs two sentences combined. Passages exist only in English and Turkish, so people with other language pairs skip this task (this changes their battery; see review F16) |
| Rule card | – | Verbal rule application / rule-based classification – to verify | study-specific | The clue states a sorting rule (colour, not-colour, number of shapes, and/or combinations); decide if the card goes to group A or B |
| Operation span (words) | – | Complex span: Daneman & Carpenter (1980); operation span: Turner & Engle (1989) | adapted | Judge 3-5 sums as right or wrong (8 s each), each followed by a word for 1 s in the trial's language; then click the words back in order. Words instead of letters; one set per trial; translated words; time measured over recall only |
| Word retention | – | Old/new recognition scored with hits and false alarms (signal detection) | study-specific | Up to 8 earlier operation-span words mixed with the same number of never-shown words. The delay is not controlled, and the word-to-language bookkeeping has known problems (review F06) |

## Task library (64 modules)

round mix**, so none of them runs in a study session unless `ROUND_MIX` is changed. The
review found that long task IDs do not fit the current database column (review F02), so
adding library tasks to real sessions is blocked until that is fixed.
